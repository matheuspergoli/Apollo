# Apollo 1.0.0

> **Problema conhecido no pacote Windows 1.0.0:** faltam `SudoVDA.dll` e
> `nefconc.exe` no diretório do driver. Isso impede instalar o display virtual em
> uma máquina que ainda não tenha o componente operacional. Não use esse pacote
> para reparar/reinstalar SudoVDA. Use a [versão corretiva 1.0.1](v1.0.1.md).
> Os arquivos publicados e a tag 1.0.0 permanecem inalterados.
>
> Antes de atualizar, preserve uma cópia privada de configurações, aplicativos,
> credenciais e pareamentos. Não desinstale a instalação existente como tentativa
> de corrigir o driver, nem confirme a remoção de dados na desinstalação.

Primeira versão deste fork com o painel React completo, em português, integrado
às configurações, aplicativos e permissões do host.

## Destaques

- Interface única em React/TypeScript, TanStack Router/Query, Tailwind e shadcn/Base UI.
- Configurações completas: 99 campos em 11 seções Windows/Linux, com 10 visíveis no Windows.
- Templates, exportação dos valores salvos e importação revisada global/por seção.
- Arquivos individuais de aplicativo e permissões sem transferir identidade ou pareamento.
- Capas PNG preservadas byte a byte; estado dos aplicativos atualizado periodicamente.
- Reinício confirmado, proteção de rascunhos e recuperação de autenticação sem repetir comandos.
- Cookie de sessão isolado por porta e ocultado nos logs de debug.
- Diálogo Artemis com link, QR e instruções para o dispositivo correto.
- Suporte de host concentrado em Windows, mantendo o código Linux existente.

## Downloads

- **Apollo-1.0.0-Windows-x64.zip:** extração manual.
- **Apollo-1.0.0-Windows-x64-installer.exe:** instalação convencional com serviço/driver/firewall.
- **SHA256SUMS.txt:** checksums dos dois pacotes.
- **SOURCE_COMMIT.txt:** commit exato usado no build.

O código-fonte correspondente está disponível nesta tag. Não há pacote binário
Linux validado nesta release. Pacotes de outros repositórios/gerenciadores não
correspondem necessariamente a este fork.

## Antes de atualizar

Faça backup privado das configurações, aplicativos, credenciais e pareamentos.
Encerre o host anterior antes de iniciar outro. Para o ZIP, use uma pasta nova;
não sobrescreva seus dados com padrões. Será necessário entrar novamente no painel.

O instalador possui ações de serviço, firewall e drivers. Ele foi compilado e seu
conteúdo foi comparado ao ZIP sem executar a instalação no host do usuário.
Não há declaração de assinatura Authenticode. Não desative proteções para ignorar alertas.

Cópias de capas corrompidas por versões anteriores devem ser reenviadas. O PNG
original não é alterado. Exportações JSON não são backup da instalação inteira.

## Validação

CI inclui testes frontend, contratos nativos, HTTPS Windows, PNG binário,
reinício autenticado e auditorias do ZIP e conteúdo do instalador.

Linux foi preservado, mas não houve validação de streaming em todas as distribuições/GPU.
Não são prometidos ganhos de desempenho ou latência não medidos.
